# 🇧🇷 Amazon Brazil E-Commerce SQL Analysis

📊 **SQL | MySQL | E-Commerce Analytics**

An end-to-end SQL analysis project exploring Brazilian e-commerce data to uncover business insights related to sales, customers, sellers, payments, product categories, reviews, and delivery performance.

## 🖼️ Project Preview

![Amazon Brazil SQL Analysis Project Preview](project-preview.png)

## 🎯 Project Objectives

- 📦 Analyze order and delivery performance
- 💰 Identify revenue trends and top-performing product categories
- 👥 Understand customer purchasing behavior
- 🏪 Evaluate seller performance
- ⭐ Analyze customer review scores
- 💳 Explore payment methods and average order value

## 🛠️ Tools Used

- 🐬 MySQL
- 🗃️ SQL
- 📈 Data analysis and business problem-solving

## 🔍 Analysis Covered

This project contains **14 SQL business questions**, covering revenue analysis, customer behavior, seller performance, payment methods, reviews, and delivery metrics.

## 📁 Project Files

- 💻 **SQL Analysis:** SQL queries used to answer the business questions
- 📄 **Project Report:** PDF containing the project analysis and results

## 🚀 Key Learning

Applied SQL concepts such as joins, aggregations, subqueries, Common Table Expressions (CTEs), window functions, and date functions to solve practical e-commerce business problems.
